# Skills Index

Use these skills as focused overlays on top of [AGENTS.md](../../AGENTS.md) and [.github/copilot-instructions.md](../../.github/copilot-instructions.md).

- `backend-api-change`: add or modify API-facing backend behavior.
- `backend-debugging`: debug a failing backend path starting from a concrete symptom.
- `instruction-maintenance`: maintain AGENTS, repo instructions, and task skills without creating duplication.

Each skill should stay narrow and task-shaped. Do not copy the full global workflow into every skill.
