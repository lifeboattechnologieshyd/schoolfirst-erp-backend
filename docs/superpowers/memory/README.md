# Memory

Store durable repo-shared memory here.

Use these files as the default anchors:

- `repo-facts.md` for verified repo facts, conventions, commands, and recurring lessons.
- `technical-preferences.md` for non-sensitive technical user preferences that affect work in this repo.
- `open-questions-and-risks.md` for unresolved questions, risks, and follow-up items.

Prefer updating these shared files over creating new memory files unless the topic is large enough to need its own durable document.
